curl及其应用

1.介绍

curl 是一个强大的命令行工具，用于在客户端和服务器之间传输数据。它支持多种协议（HTTP、HTTPS、FTP、SFTP、SMTP 等），常用于测试 API、下载文件、调试网络请求等场景。
看到这类应用场景，有些人会想到burp，不过它们两个并非可替代的关系，而是各有所长：

  • burp的可视化界面对新手极其友好，擅长拦截请求并对其观察分析，其内置的intruder功能更是省去了用python写脚本的功夫，大大提高爆破的效率。
  • 在真实的渗透测试场景中，curl的适用性更广。
    1.当你通过 SSH 连接到一个没有图形界面的服务器（如云主机或跳板机）时，burp很大概率是没有安装的，而curl 几乎总是预装的。在这种情况下，它是你发送 HTTP 请求、测试内网服务的唯一便捷选择。
    2.其次它可以生成一键可复现的Poc，这一点在src里面尤为重要。厂商不需要按照你在burp上面的的操作一步步验证漏洞存在，打开终端一键复制粘贴就能复现。
    接下来就练习一下这个命令如何使用

其中200是状态码的一种，它表示服务器正常返回资源，页面正常加载的意思。常见的状态码：

  • 2xx
  • 3xx：重定向，例如页面跳转，一般返回302、301
  • 4xx：客户端错误，如：
    400 Bad Request：请求语法错误，服务器看不懂。通常是客户端发错了数据。
    401 Unauthorized：未认证。你需要登录或提供有效的身份凭证。
    403 Forbidden：服务器知道你是谁，但是你没有权限，禁止访问
    404 Not Found：服务器找不到你请求的资源（链接错了或页面被删了）
  • 5xx：服务器出现错误
    如果响应头和内容都要看的话，就把-I改成-i

-X用来指定方法，-d用来发送请求体数据。发送之后服务器会返回JSON：

  • “args“：是URL 里的查询参数（?key=value）。发送的URL 里没有 ?，所以是空的。如果你请求 https://httpbin.org/post?key=value，这里就会显示 {"key": "value"}。
  • “headers“：是请求头，Accept是接受返回的类型，*/* 意思就是什么类型都可以。
  • Content-Length和Content-Type分别用来告诉服务器我发送的数据格式和数据长度。
  • “origin“: 这是服务器检测到的IP，注意这个是公网IP，是出去的地方，而ifconfig看到的IP是自己的
  • “form“: 这是数据真正被解析的地方，因为Content-Type是表单格式，所以服务器自动把请求体解析成了键值对

6.自定义请求头

第四个例子中服务器会返回我们的一些信息，比如User-Agent。它有以下功能：

  1. 适配设备：识别是手机还是电脑，返回对应版本的页面
  2. 数据统计：统计访问者用什么浏览器、什么系统
  3. 识别爬虫：搜索引擎的爬虫 UA 里会写明身份，如 Googlebot
  4. 限制访问：有些网站发现 UA 是 curl 或 python-requests，会拒绝或限制，认为是程序而不是真人
