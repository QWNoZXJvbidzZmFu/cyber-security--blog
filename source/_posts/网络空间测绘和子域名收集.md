### 搜索引擎介绍
ZoomEye（“钟馗之眼”） 是由知道创宇404实验室打造的网络空间测绘搜索引擎：
https://www.zoomeye.org
- 它和百度、Google最根本的区别在于索引对象：传统搜索引擎索引的是网页内容，而ZoomEye索引的是网络空间中的资产本身——IP、端口、服务、协议 banner、设备指纹、证书等。
- 通过分布在全球的测绘节点，它持续探测 IPv4/IPv6 地址与域名，最终实现对网络空间的“画像”。在覆盖维度上，ZoomEye 同时兼顾主机设备层（路由器、摄像头、服务器开放端口）与 Web 应用层（CMS 指纹、Web 框架、证书信息），这一双维度设计是它区别于早期同类工具的重要特征。
- 类似这样的网络空间搜索引擎还有很多，如 https://fofa.info/ ，奇安信的 https://hunter.qianxin.com ，国外的 https://www.shodan.io 等等

### 子域名收集
**子域名（Subdomain）** 是主域名前面加的一段前缀，用来把一个大网站拆分成多个独立的服务或板块。它的收集方法分被动收集（用在线平台/工具查现成数据）和主动爆破（用字典跑 DNS 查询）。

#### 主动爆破
写一个python脚本：
```python
import socket  
import concurrent.futures  
DOMAIN = "example.com"  
SUBDOMAINS = [  
    "www", "mail", "ftp", "dev", "test", "api", "blog",  
    "admin", "vpn", "ns1", "ns2", "smtp", "pop", "webmail",  
    "portal", "shop", "cdn", "static", "m", "app"  
]  
  
def check(sub):  
    full = f"{sub}.{DOMAIN}"  
    try:  
        ip = socket.gethostbyname(full)  
        return (full, ip, True)  
    except socket.gaierror:  
        return (full, None, False)  
  
def main():  
    found = []  
    failed = 0  
    with concurrent.futures.ThreadPoolExecutor(max_workers=20) as executor:  
        results = executor.map(check, SUBDOMAINS)  
        for full, ip, ok in results:  
            if ok:  
                found.append((full, ip))  
                print(f"[+] 成功  {full:30s} -> {ip}")  
            else:  
                failed += 1  
                print(f"[-] 失败  {full:30s} -> 无法解析")  
  
    print(f"\n共 {len(SUBDOMAINS)} 个候选，成功 {len(found)} 个，失败 {failed} 个")  
  
if __name__ == "__main__":  
    main()
```
之后点击运行就能查看搜集情况。真实情况下的字典比该脚本里面的大得多，这里只是做个示范。
==🔴注意主动爆破会向目标 DNS 服务器发送大量查询，务必只对你拥有或获得明确授权的域名操作。==
